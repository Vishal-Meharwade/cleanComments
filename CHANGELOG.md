# Change Log

All notable changes to the "CleanComments" extension will be documented in this file.

## [1.0.0] - 2025-09-27

### Added
- Initial release
- Remove all comments functionality for multiple programming languages
- Improve comments feature with basic formatting enhancements
- Support for JavaScript, TypeScript, Python, HTML, CSS, Java, C/C++, Shell, SQL, Ruby, and PHP
- Keyboard shortcut (Ctrl+Alt+C) for quick comment removal
- Context menu integration
- Command palette integration

### Features
- Multi-language comment detection and removal
- Smart comment improvement with capitalization and punctuation
- Empty line cleanup after comment removal
- User-friendly notifications and error handling
